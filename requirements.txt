PLATFORM-SPECIFIC PHP INSTALL:
------------------------------
Windows (XAMPP):
  1. Download XAMPP PHP 8.5+: https://www.apachefriends.org/download.html
  2. Install to C:\xampp
  3. Edit C:\xampp\php\php.ini - uncomment all extensions above
  4. Set extension_dir = "ext"
  5. Add C:\xampp\php to Windows PATH

macOS (Homebrew):
  brew install php@8.5 composer node git mysql
  brew link --force --overwrite php@8.5

Linux Ubuntu/Debian:
  sudo apt update && sudo apt install -y \
    php8.5 php8.5-cli php8.5-common php8.5-mysql php8.5-sqlite3 \
    php8.5-mbstring php8.5-xml php8.5-curl php8.5-zip php8.5-gd \
    php8.5-bcmath php8.5-tokenizer php8.5-fileinfo \
    composer nodejs npm git mysql-server

================================================================================
DATABASE OPTIONS
================================================================================

DEFAULT (DEVELOPMENT): SQLite
------------------------------
- File: database/database.sqlite
- Zero configuration
- Run: touch database/database.sqlite && php artisan migrate --force

PRODUCTION: MySQL 8+ / MariaDB 10.6+
-------------------------------------
- Create database: CREATE DATABASE it_asset_management CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
- Create user: CREATE USER 'asset_user'@'%' IDENTIFIED BY 'strong_password';
- Grant: GRANT ALL PRIVILEGES ON it_asset_management.* TO 'asset_user'@'%';
- Update .env with DB credentials

================================================================================
ONE-COMMAND INSTALL (RUN THIS ON NEW DEVICE)
================================================================================

PREREQUISITE: Ensure PHP, Composer, Node.js, Git are installed and in PATH.
              Enable required PHP extensions in php.ini first (see above).

COPY-PASTE THIS ENTIRE BLOCK INTO YOUR TERMINAL:
================================================================================

# ============================================================================
# COMPLETE AUTOMATED SETUP - COPY & RUN THIS
# ============================================================================

set -e  # Exit on error

echo "=========================================="
echo "IT ASSET MANAGEMENT SYSTEM - AUTO SETUP"
echo "=========================================="

# 1. CLONE REPOSITORY
if [ ! -d "IT-Asset-Management-System" ]; then
    echo "[1/8] Cloning repository..."
    git clone https://github.com/jatinkumarmajoka/IT-Asset-Management-System.git
fi
cd IT-Asset-Management-System

# 2. VERIFY PREREQUISITES
echo "[2/8] Verifying prerequisites..."
php -v | grep -q "8.5" || { echo "ERROR: PHP 8.5+ required"; exit 1; }
composer --version >/dev/null || { echo "ERROR: Composer not found"; exit 1; }
node -v | grep -q "v2[0-9]" || { echo "ERROR: Node.js 20+ required"; exit 1; }
npm -v >/dev/null || { echo "ERROR: npm not found"; exit 1; }
git --version >/dev/null || { echo "ERROR: Git not found"; exit 1; }
echo "    All prerequisites OK"

# 3. INSTALL PHP DEPENDENCIES
echo "[3/8] Installing PHP dependencies (Composer)..."
composer install --no-interaction --prefer-dist --optimize-autoloader

# 4. INSTALL NODE DEPENDENCIES
echo "[4/8] Installing Node dependencies (npm)..."
npm ci

# 5. CONFIGURE ENVIRONMENT
echo "[5/8] Configuring environment..."
if [ ! -f .env ]; then
    cp .env.example .env
    php artisan key:generate --no-interaction
    echo "    Created .env and generated APP_KEY"
else
    echo "    .env already exists"
fi

# 6. DATABASE SETUP (SQLite for local dev)
echo "[6/8] Setting up database..."
if [ ! -f database/database.sqlite ]; then
    touch database/database.sqlite
    echo "    Created database/database.sqlite"
fi
php artisan migrate --force --no-interaction

# 7. (OPTIONAL) SEED DEMO DATA
echo "[7/8] Seeding demo data (optional)..."
php artisan db:seed --force --no-interaction 2>/dev/null || echo "    Seeder skipped or failed (non-critical)"

# 8. BUILD FRONTEND ASSETS
echo "[8/8] Building frontend assets..."
npm run build

echo ""
echo "=========================================="
echo "SETUP COMPLETE!"
echo "=========================================="
echo ""
echo "Next steps:"
echo "  1. Create Super Admin:  php artisan app:create-super-admin"
echo "  2. Start dev server:    php artisan serve"
echo "  3. Open browser:        http://127.0.0.1:8000"
echo ""
echo "For production deployment, see SETUP.txt or SETUP.md"
echo "=========================================="

# ============================================================================
# END OF ONE-COMMAND SETUP
# ============================================================================

================================================================================
TROUBLESHOOTING QUICK FIXES
================================================================================

| Error                          | Fix Command |
|--------------------------------|-------------|
| could not find driver (PDO)    | Enable pdo_mysql/pdo_sqlite in php.ini, restart PHP |
| No application encryption key  | php artisan key:generate |
| Permission denied (storage)    | chmod -R 755 storage bootstrap/cache |
| Vite manifest not found        | npm run build |
| npm ERR! code ENOLOCK          | npm i --package-lock-only && npm ci |
| Composer platform req failed   | composer install --ignore-platform-req=ext-gd |
